upload_kit — 개인용 유튜브 영상 업로드 도구

채널 운영자 본인이 자기 PC 에서 쓰는 도구입니다. 다른 사람에게 배포하거나 판매하지 않습니다.

무엇을 하나요

upload_kit 은 채널 운영자가 직접 검토하고 「올려도 된다」고 승인한 영상만, 운영자 자신의 유튜브 채널에 올리는 명령줄 도구입니다.

  • 운영자가 승인 폴더로 옮긴 영상과 제목·설명 문구를 읽어, YouTube Data API 로 비공개 + 예약 공개로 올립니다.
  • 올리기 전에 로그인한 채널이 올릴 채널과 같은지 확인하고, 같은 영상을 두 번 올리지 않도록 운영자 PC 의 기록과 채널의 최근 업로드 목록을 대조합니다.
  • 올린 뒤에는 영상의 처리 상태와 공개 예약 시각을 확인해 운영자 PC 의 기록에 남깁니다.

개인정보

이 도구가 구글 계정에서 받는 권한과 정보를 어떻게 다루는지는 개인정보처리방침에 적어 두었습니다. 로그인 열쇠와 기록은 운영자 PC 에만 있고, 외부 서버로 보내거나 누구와도 공유하지 않습니다.

YouTube API 서비스

이 도구는 YouTube API 서비스를 사용합니다. 이 도구를 쓰는 것은 YouTube 서비스 약관에 동의하는 것이며, 구글이 정보를 다루는 방식은 Google 개인정보처리방침을 따릅니다. upload_kit 은 YouTube·Google 과 관계없는 개인용 도구입니다.
