upload_kit 개인정보처리방침

시행일 2026-10-03 · upload_kit 홈페이지

1. 누가 쓰나요

upload_kit 은 유튜브 채널 운영자 본인(채널 소유자 또는 그 채널의 브랜드 계정 관리자)이 자기 PC 에서 자기 채널에 영상을 올릴 때만 쓰는 개인용 도구입니다. 다른 사람에게 배포하거나 판매하지 않으며, 다른 사람의 계정으로 로그인하지 않습니다.

2. 요청하는 권한과 이유

  • https://www.googleapis.com/auth/youtube.upload — 운영자가 승인한 영상을 운영자의 채널에 올리기 위해
  • https://www.googleapis.com/auth/youtube.readonly — 로그인한 채널이 올릴 채널과 같은지 확인하고, 올린 영상의 처리 상태·공개 범위·예약 시각을 확인하고, 같은 영상을 두 번 올리지 않도록 채널의 최근 업로드 목록을 대조하기 위해

영상을 지우거나 채널 설정을 바꾸는 권한은 요청하지 않습니다. 비밀번호는 다루지 않습니다(로그인은 구글의 로그인 화면에서 합니다).

3. 다루는 정보

  • 로그인한 채널의 채널 ID · 채널 이름 · 핸들
  • 이 도구로 올린 영상의 영상 ID · 제목 · 처리 상태 · 공개 범위 · 예약 시각
  • 중복 확인을 위한 채널의 최근 업로드 목록(영상 ID · 제목 · 올린 파일 이름)

4. 저장

  • 로그인 열쇠(갱신 토큰)는 운영자 PC 에 Windows 사용자 계정 암호화(DPAPI)로만 보관합니다. 그 PC 의 그 Windows 사용자만 풀 수 있습니다.
  • 업로드 기록(영상 ID · 제목 · 시각 · 상태)은 운영자 PC 의 기록 파일에 남습니다.
  • 어떤 정보도 외부 서버로 보내지 않습니다(구글·유튜브 API 호출 자체는 빼고).

5. 공유와 사용 제한

구글 API 로 받은 정보를 누구와도 공유하거나 팔지 않으며, 광고 · 분석 · 인공지능 학습에 쓰지 않습니다. 위 2·3 의 목적에만 씁니다.

upload_kit's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

6. 취소와 삭제

  • 언제든 구글 계정의 서드 파티 앱 및 서비스에서 upload_kit 의 접근을 취소할 수 있습니다. 구글의 보안 설정 — 앱 액세스 권한에서도 취소할 수 있습니다.
  • 도구의 logout 명령은 구글에 취소를 요청하고 PC 에 보관한 로그인 열쇠를 지웁니다.
  • 업로드 기록은 운영자 PC 의 기록 파일을 지우면 없어집니다.

7. YouTube API 서비스 이용 고지

이 도구는 YouTube API 서비스를 사용합니다. YouTube 서비스 약관 · Google 개인정보처리방침
